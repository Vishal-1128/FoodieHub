**FoodieHub** is a modern, clean, and fully responsive frontend web application for online food ordering, inspired by industry leaders like **Swiggy**, **Zomato**, and **Uber Eats**. Built from scratch using semantic HTML5, modern CSS3 (Grid & Flexbox), and Vanilla JavaScript.

---

## ✨ Features

- **Modern UI/UX:** Clean, appetizing interface with sticky navigation, smooth scroll, and subtle hover animations.
- **Fully Responsive Layout:** Adapts seamlessly across desktop monitors, tablets, and mobile smartphones.
- **Category Filtering:** Instant filtering across cuisines (*Burgers, Pizza, Biryani, Healthy, Desserts*).
- **Real-Time Search:** Live search bar that filters dishes by name, category, or description as you type.
- **Interactive Slide-Out Cart:**
  - Add items directly from the menu cards.
  - Increment (`+`) or decrement (`-`) item quantities dynamically.
  - Automatic calculation of item subtotal, delivery fee, and final total.
  - Live cart badge counter in the navbar.
- **Order Confirmation Modal:** Interactive checkout experience with estimated delivery time feedback.
